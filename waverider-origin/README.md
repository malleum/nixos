# Waverider-Origin

An [Origins-Reborn](https://modrinth.com/plugin/origins-reborn) addon (Paper
1.21.x) adding the **Waverider** origin — a skimmer of the sea's skin who runs
on water and lava but fears the hard earth and the deep places.

> This project is currently vendored inside the `nixos` flake repo (it is
> deployed from here, see *Deploying* below) but is fully self-contained and
> intended to eventually move to its own repository — nothing in here refers
> back to the surrounding repo.

## The origin

| Power | Key | Effect |
|---|---|---|
| Surface Tension | `waverider:fluid_walker` | Water and lava are solid ground to you. While striding the surface you have **Speed II**, and lava underfoot cannot burn you. **Sneak** to slip beneath and swim. Landing from a fall onto a fluid is landing on *stone* — dive (hold sneak) or clutch, or eat the fall damage. |
| Wavecatch | `waverider:water_clutch` | While falling, tap **sneak** within 10 blocks of a surface: a momentary wave (a real, non-flowing water block, 1 s lifetime) appears on it and breaks your fall. Every attempt — hit or miss — starts a **1 s cooldown**, so pressing too early means going splat. A catch from beyond safe-fall height grants **Speed I + Regeneration I + Night Vision for 60 s**. |
| Hard Landing | `waverider:hard_landing` | Double damage from falling and from flying into blocks. |
| Shallow Lungs | `waverider:shallow_lungs` | Your breath runs out twice as fast underwater. |
| Featherweight | `waverider:leather_only` | Only leather armor may be worn. An elytra (no protection) still fits. |
| Vegetarian | `origins:vegetarian` | Built-in Origins-Reborn power: no meat, fish included. |

Impact rating: 3 (high). The kit trades top-tier late-game defense (leather
cap) and underwater capability for unmatched overworld/nether mobility.

## How Surface Tension works

The top fluid block under the player is replaced **client-side** with an
invisible barrier (`Player#sendBlockChange`), so ordinary client physics make
the surface walkable — running, sprint-jumping, knockback all behave like
land. The real world is never modified. Because the server believes the player
is hovering, flight is temporarily allowed to suppress the vanilla
"Flying is not enabled" kick (actually engaging flight is cancelled).
Sneaking (or losing the ability) withdraws the fake floor and resyncs the
client with the real blocks.

Wavecatch places a **real** water block (physics suppressed, `BlockFromToEvent`
cancelled) and reverts it after 20 ticks; Surface Tension explicitly refuses to
solidify an active clutch wave so the catch always works while sneaking.

## Config

Generated by Origins-Reborn into `plugins/Origins-Reborn/ability-config.yml`:

```yaml
waverider:
  water_clutch:
    cooldown-duration: 20   # ticks
    range: 10               # blocks
    buff-duration: 1200     # ticks
    min-fall-blocks: 3      # minimum fall for the reward buff
  hard_landing:
    multiplier: 2.0
  leather_only:
    allowed-armor: [LEATHER_HELMET, LEATHER_CHESTPLATE, LEATHER_LEGGINGS, LEATHER_BOOTS, ELYTRA]
```

Ability titles/descriptions land in `translations.yml` and can be reworded there.

## Building

Requires JDK 21 and Gradle (e.g. `nix shell nixpkgs#gradle nixpkgs#jdk21`):

```
gradle build
# → build/libs/Waverider-Origin-<version>.jar
```

Compile-time deps resolve from the PaperMC repo (`paper-api`) and Modrinth's
maven (`maven.modrinth:origins-reborn`); both are `compileOnly` so the jar is
tiny and has no bundled dependencies.

## Deploying (while vendored in the nixos repo)

`modules/services/mc.nix` copies the **committed** jar
`modules/services/Waverider-Origin.jar` into the server's `plugins/` on every
service start. After changing the source:

```
cd waverider-origin
gradle build
cp build/libs/Waverider-Origin-*.jar ../modules/services/Waverider-Origin.jar
git add -A && git commit && git push
# then on the server host: git pull && nh os switch
```

When this project moves to its own repo, publish the jar as a release artifact
and switch mc.nix to fetch it like the other plugins instead of committing the
binary.
